# Metroris 2.0 — социальная сеть с Supabase

В проекте есть регистрация/вход по email, профили, общая лента, публикации с фото, лайки, комментарии, личные сообщения и простая админ-модерация. Это стартовый MVP, а не готовая промышленная соцсеть.

## 1. Создай бесплатную базу данных Supabase
1. Открой https://supabase.com и создай аккаунт.
2. Создай новый проект (Free plan). Придумай пароль базы данных и сохрани его.
3. Дождись создания проекта.
4. Открой **Project Settings → API** (или **Connect**) и скопируй **Project URL** и **anon/public key**. Не используй `service_role` key.
5. В проекте открой **SQL Editor → New query**, вставь весь текст из файла `supabase-setup.sql` и нажми **Run**.
6. В **Authentication → URL Configuration** добавь адрес сайта в **Site URL** и **Redirect URLs**. Для локального теста добавь `http://localhost:8000/**`. Для GitHub Pages потом добавь `https://ТВОЙ-ЛОГИН.github.io/metroris/**`.

## 2. Подключи сайт к Supabase
1. Открой `app.js` в редакторе (например, Блокнот или VS Code).
2. В первых двух строках настройки замени:
   - `ВСТАВЬ_URL_ПРОЕКТА` на Project URL.
   - `ВСТАВЬ_ANON_PUBLIC_KEY` на anon/public key.
3. Сохрани файл. Публичный anon key предназначен для браузера; безопасность обеспечивается политиками RLS из SQL. **Никогда не вставляй `service_role` key в сайт.**

## 3. Запуск на компьютере
1. Открой терминал в папке проекта.
2. Выполни `python -m http.server 8000`.
3. Открой `http://localhost:8000`.
   (Если Python не установлен, можно использовать расширение Live Server в VS Code.)

## 4. Бесплатная публикация через GitHub Pages
1. Создай публичный репозиторий `metroris`.
2. Загрузи в корень репозитория `index.html`, `styles.css`, `app.js`.
3. В **Settings → Pages** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажми **Save**.
4. Дождись публикации. Адрес будет `https://ТВОЙ-ЛОГИН.github.io/metroris/`.
5. Добавь этот URL в Supabase **Authentication → URL Configuration → Redirect URLs**.
6. Открой сайт, зарегистрируйся и подтверди email, если Supabase попросит.

## 5. Сделай себя администратором
После регистрации открой Supabase → **Table Editor → profiles**. Найди свою строку и поменяй `role` с `user` на `admin`. После повторного входа появится раздел «Админ-панель». Никогда не выдавай роль admin незнакомым пользователям.

## Важно про безопасность и ограничения
- В браузер вставляется только `anon/public` key. `service_role` key — секрет, его нельзя публиковать.
- В SQL включён Row Level Security (RLS). Не отключай RLS и не удаляй политики.
- Сообщения доступны только отправителю и получателю по RLS. Публичны профили, посты, комментарии и лайки.
- Фото загружаются в публичный bucket; не загружай приватные изображения.
- Это MVP: нет восстановления пароля в интерфейсе, жалоб, блокировок, антиспам-системы, push-уведомлений, realtime-обновлений и полноценного аудита админ-действий. Для публичного запуска добавь модерацию, лимиты запросов, защиту от злоупотреблений и политику конфиденциальности.
- Бесплатные тарифы Supabase и GitHub Pages имеют лимиты и могут менять условия.
